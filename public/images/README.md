# How to add your own photos

This site loads photos from this `public/images/` folder by filename. Drop a
JPG or PNG in the right spot using the **exact filename** below (any
resolution works — 1200px on the long edge is plenty) and it appears on the
site automatically, no code changes needed. Until a file exists, a styled
placeholder is shown instead, so the site never breaks.

## Where to get free photos

If you don't have your own restaurant photography yet, these sites offer
free, no-attribution-required stock photos — search each filename's subject
(e.g. "grilled chicken bowl", "burger", "restaurant interior"):

- https://unsplash.com
- https://www.pexels.com

Download, rename to match the list above, and drop into the matching folder.

## Renaming tip

On Mac/Linux you can rename in bulk from the terminal, e.g.:
```bash
mv ~/Downloads/photo123.jpg public/images/menu/classic-burger.jpg
```
On Windows, just right-click → Rename in File Explorer.
